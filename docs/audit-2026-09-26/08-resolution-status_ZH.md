## 已确认的产品边界

- 先完成**本机长期运行**，不把其他 Mac 的独立安装、签名、公证列入本轮完成条件。
- 从 Markdown 目录同步的文档在 App 中编辑正文时直接写回源 Markdown 文件；标题与作者由源文件管理。SQL 先提交待写意图，文件原子替换失败时 API 回 `202/source_status=pending`，启动时重试，目录同步在待写期间中止；外部冲突不会静默覆盖，仍需人工核对。未迁移的 Windows 源路径不可写回。
- 本机读接口按同一登录用户可信；解锁前缀只是搜索过滤，不宣称是授权隔离。仍需明确其他本机用户/进程的风险与文件权限。
- 旧 Windows Markdown 根路径**暂不迁移**；没有实际 macOS 路径映射，DATA-09 的真实数据迁移保持用户暂缓，不能标为完成。
- 真实资料库目前只允许只读核验和备份恢复演练；服务重启、实际迁移或索引认领前必须再次确认。
